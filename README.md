HAPPY BIRTHDAY, MY LOVE

Open index.html in a modern browser. No installation or build is required.
Alternatively, serve this folder with any simple local web server.
Keep index.html, style.css, script.js, images/, fonts/, and audio/ together.

Pages: Welcome -> Birthday letter -> For you -> Our Beautiful Memories
-> Final surprise. Each Back button returns to the previous screen.

All six original photos are included. Fonts are bundled for offline use.
Music starts when you press Play music or reach the final surprise.
No song recording was provided in the existing project. The site plays
its built-in traditional Happy Birthday melody when no audio file exists.
To use your own recording, put birthday-song.mp3 inside audio/.

The separate Memories screen has been reconstructed from the supplied
reference screenshot because its original HTML was not in the project.
Its photographs use the existing original files, not replacements.
